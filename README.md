# Wurst Client

> **Minecraft Hacked Client** | Version v7.45 | Platform: Java Edition 1.8 – 1.21.4

## About

Wurst Client is one of the oldest and most reliable open-source hacked clients for Minecraft. Supports a wide range of versions and includes over 100 modules for griefing, utility and PvP.

- KillAura
- Nuker
- AutoMine
- X-Ray
- Tracers
- ESP
- Fly

- NoFall
- Scaffold
- AutoFish
- Search
- TunnelFinder
- AntiAFK

## System Requirements

- Open source — available on GitHub
- Fabric mod loader required
- Wide version support from 1.8 to latest
